# Chemical Equilibrium Discovery — General Chemistry 2545, Oranim

Self-contained interactive Hebrew activity on reversible reactions, discovery of the equilibrium constant, and predicting net reaction direction using Q.

## Publish with GitHub Pages

1. Create a new repository on GitHub (e.g. `chemical-equilibrium-discovery`).
2. Upload **`index.html`** and **`README.md`** from this ZIP to the repository root; commit them to the default branch.
3. In **Settings → Pages**, select **Deploy from a branch**, the default branch, and **/(root)**; save.
4. Open the GitHub Pages URL that GitHub displays after deployment.

For a local preview, double-click `index.html` in a browser. It is self-contained and has no CDN or server dependencies.

## Content
- Investigation 1: `A ⇌ B` hidden equilibrium relationship
- Investigation 2: `A ⇌ B + C` relationship across three components
- Investigation 3: `Q` versus equilibrium condition and direction prediction
- Restart/reset controls; fixed temperature (no temperature adjustments)
